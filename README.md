# PresentationCard — Logic Code Spot

Tarjeta digital de **Dostin Santana** (Logic Code Spot).

## URL de producción

**https://presentation-card-zeta.vercel.app/**

Úsala en QR / WhatsApp / Instagram para presentarte. GitHub: [Dostindev8/PresentationCard](https://github.com/Dostindev8/PresentationCard).

## Local

Abre `index.html` en el navegador, o:

```bash
npx serve .
```

## Stack

HTML autocontenido · tema claro/oscuro · vCard QR · descarga PDF · Vercel.
